# armani-vazquez-portfolio

Personal portfolio for Armani Vazquez. A static site with no build step: `index.html`, `css/styles.css`, `js/main.js`, and self-hosted images and fonts.

## Publish on GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. The site appears at:
https://lilmoniisenterprise.github.io/armani-vazquez-portfolio/

On Netlify or another host, leave the build command empty and publish the repo root. Then update the canonical and `og:` addresses in `index.html` and the `/armani-vazquez-portfolio/` paths in `404.html`.

## Edit

- Page text is in `index.html`. Brands, demos, and live demo links are in the lists at the top of `js/main.js`.
- Colors are at the top of `css/styles.css`.
- Replace an image by saving over the file in `images/`.

# armani-vazquez-portfolio

Personal portfolio for Armani Vazquez. A static site with no build step: `index.html`, `css/styles.css`, and self-hosted images and fonts.

## Publish on GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. The site appears at:
https://lilmoniisenterprise.github.io/armani-vazquez-portfolio/

On Netlify or another host, leave the build command empty and publish the repo root. Then update the canonical and `og:` addresses in `index.html` and the `/armani-vazquez-portfolio/` paths in `404.html`.

## Edit

- Text and links are in `index.html`.
- Colors are at the top of `css/styles.css`. Hero colors must keep strong contrast with the dark ink text.
- Replace a gallery image by saving over the file in `images/`.
